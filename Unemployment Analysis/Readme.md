# Unemployment Analysis with Python

## Project Overview

This project analyzes unemployment trends in India using Python.

The analysis focuses on:

- State-wise unemployment rates
- COVID-19 impact on unemployment
- Urban vs Rural unemployment comparison
- Monthly unemployment trends

## Technologies Used

- Python
- Pandas
- Matplotlib

## Dataset Information

The dataset contains:

- Region
- Date
- Frequency
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area

## Analysis Performed

1. Data Cleaning
2. Missing Value Analysis
3. Statistical Analysis
4. State-wise Unemployment Analysis
5. COVID Impact Analysis
6. Urban vs Rural Analysis
7. Data Visualization

## Key Findings

- Average unemployment rate was approximately 11.79%.
- Highest unemployment rate observed was 24.88% during May 2020.
- COVID-19 significantly increased unemployment rates.
- Certain states such as Tripura showed higher unemployment rates than others.
- Unemployment varied between Urban and Rural regions.
