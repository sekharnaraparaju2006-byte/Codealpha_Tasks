# Project 2: Unemployment Analysis in India

## Objective

Analyze unemployment trends in India and study the impact of COVID-19 on unemployment rates.

## Techniques Used

- Data Cleaning
- Statistical Analysis
- State-wise Analysis
- Monthly Trend Analysis
- Urban vs Rural Comparison
- Data Visualization

## Key Findings

- Average unemployment rate was approximately 11.79%.
- Highest unemployment rate was observed during May 2020.
- COVID-19 significantly increased unemployment rates.
- Urban unemployment was higher than rural unemployment.

## Visualizations

- Unemployment Rate Over Time
- Distribution of Unemployment Rate
- Top 10 States by Average Unemployment Rate
- Urban vs Rural Comparison

# Project 3: Car Price Prediction

## Objective

Predict the selling price of used cars using machine learning techniques.

## Techniques Used

- Data Cleaning
- Exploratory Data Analysis
- Feature Encoding
- Train-Test Split
- Linear Regression

## Key Findings

- Present Price strongly influences Selling Price.
- Diesel cars generally have higher average resale value.
- Older cars tend to have lower selling prices.

## Model Performance

- R² Score: 0.8489
- The model explains approximately 84.89% of the variation in car prices.

## Visualizations

- Selling Price Distribution Histogram
- Present Price vs Selling Price Scatter Plot
